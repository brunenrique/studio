# **App Name**: PsiGuard

## Core Features:

- Role Management: Secure user authentication and authorization system with role-based permissions (Admin, Psychologist, Secretary).
- Secure Patient Records: Secure electronic health records with basic patient data (name, contact, date of birth, session notes) and client-side encryption for sensitive fields.
- Appointment Management: Appointment management functionality to create, edit, cancel, and reschedule appointments, including a calendar view.
- Attendance Tracking: Mark attendance, absence, or rescheduling directly in the appointment schedule.
- Session Notifications: Automated email reminders for upcoming sessions (24 hours and 30 minutes before).
- Waiting List: Functionality to add patients to a waiting list and move them to available time slots.
- AI-Driven Session Insights: After session notes have been written, analyze notes and historical session data, using a tool to surface contextualized warnings or concerns within the patient record.
- Global System Settings: Configure default availability, session duration, blocked times and service integrations.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) to promote a sense of calmness and trust.
- Background color: Very light blue (#F0F8FF). This nearly white color creates a clean and professional look.
- Accent color: Soft lavender (#E6E6FA) for highlights and interactive elements. This color choice evokes relaxation.
- Body font: 'PT Sans', sans-serif, suitable for both headlines and body text, creating a modern and approachable feel.
- Use simple, professional icons that align with a clean user interface and are related to appointments and health records.
- Maintain a clean, spacious, and organized layout that prioritizes information clarity and is accessible. Minimize visual clutter.
- Subtle transitions and animations should be used sparingly to enhance user interaction without being distracting.
